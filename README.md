# RelayForge / 铸流

## 把节点、隧道和端口转发，收进一个清晰可控的控制面

RelayForge 是一套面向自有网络和远程维护场景的转发控制平台。

无论节点分布在云服务器、家庭网络、办公室还是内网环境，都可以通过一个简洁的控制台完成节点接入、链路编排、端口映射、运行监控和故障诊断。

它不只是一个端口转发工具，更是一套可以持续管理网络连接的控制面。

---

## 为什么选择 RelayForge

当节点数量增加、网络环境变复杂之后，传统的命令行配置往往会带来几个问题：

- 配置分散在不同服务器上，难以统一查看。
- 节点是否在线、链路是否正常，需要逐台登录确认。
- 修改一个端口或目标地址，容易遗漏相关配置。
- 内网机器没有公网地址，远程访问和维护变得困难。
- 流量、限速和服务状态缺少统一管理。

RelayForge 将这些操作集中到一个面板中，让网络转发从“逐台配置”变成“统一编排”。

---

## 核心能力

### 一眼掌握网络状态

在总览页集中查看：

- 节点在线状态
- CPU 和内存使用情况
- 网络收发流量
- 正在运行的转发服务
- 节点与转发流量排行
- 当前网络健康状态

节点状态通过实时通信更新，重要变化无需手动登录每台服务器检查。

### 节点统一接入

通过面板创建节点后，即可生成对应的安装命令。

支持：

- Linux AMD64
- Linux ARM64
- Windows AMD64
- 节点版本和在线状态上报
- 节点 CPU、内存和流量监控
- Linux systemd 服务
- Windows 自动启动服务
- Agent 自动升级和完整性校验

节点只需要运行一个轻量 Agent，即可被 RelayForge 纳入统一管理。

### 灵活的链路编排

根据网络结构选择合适的连接方式：

| 模式 | 适用场景 |
| --- | --- |
| 直连 | 节点可以直接访问目标服务 |
| 中继 | 入口节点和目标服务之间需要经过另一台节点 |
| 反向中继 | 目标机器没有公网地址，但可以主动连接公网节点 |

入口、出口、中继和目标之间的关系在面板中清晰呈现，复杂网络也能按链路进行管理。

### TCP / UDP 端口转发

每条转发服务都可以独立配置：

- 服务名称
- 入口端口
- 中继内部端口
- 目标地址
- TCP / UDP 转发
- 多目标地址
- 故障切换策略
- 轮询、随机和固定来源策略
- 网卡绑定
- 流量上限
- 暂停和恢复状态

端口可以手动指定，也可以从节点端口池中自动分配，并自动检查端口占用情况。

### 内网穿透与反向中继

没有公网 IP 的机器也可以被安全接入。

典型流程：

1. 在公网服务器上运行入口节点。
2. 在内网机器上安装 RelayForge Agent。
3. 内网机器主动连接公网入口。
4. 在面板中创建反向中继隧道。
5. 为不同服务创建多个公网端口映射。

内网机器不需要暴露内部服务端口，只需要保持到公网入口的出站连接。

适用于：

- 远程桌面
- 内网 Web 服务
- 家庭实验室
- 办公室内部系统
- 内网数据库和文件服务
- 远程设备维护

### 运行监控与故障诊断

遇到连接问题时，可以直接从面板发起诊断：

- 检查节点是否在线
- 检查入口到出口的链路
- 检查目标 TCP 端口
- 查看平均连接耗时
- 查看连接失败率
- 检查出口节点的外部网络能力

转发服务和隧道都可以独立诊断，帮助快速判断问题出在节点、链路、端口还是目标服务。

### 流量和限速控制

RelayForge 支持多层级的流量控制：

- 单条转发流量上限
- 隧道总流量上限
- 单向或双向统计
- 流量统计倍率
- 隧道级限速
- 用户级流量和资源限制
- 流量超额自动暂停

对于多人共享节点、按资源分配或长期运行的服务，可以更加清楚地控制带宽和流量使用。

### 一键部署，快速上线

面板支持一条命令完成部署：

~~~bash
curl -fsSL https://github.com/WayneDuan/RelayForge-Release/releases/latest/download/panel_install.sh | bash
~~~

安装脚本会自动完成 Docker Compose 配置、数据库初始化、前后端镜像拉取和管理员账号创建。安装过程中只需要设置访问端口和管理员密码，完成后即可打开面板使用。

节点接入也由面板自动生成 Linux 和 Windows 安装命令，复制到目标机器执行即可。

## 一个典型使用流程

~~~text
创建面板
   |
   v
接入节点
   |
   v
创建隧道
   |
   v
配置端口转发
   |
   v
实时监控与诊断
~~~

从部署到建立第一条转发链路，核心操作都可以在面板中完成：

1. 部署 RelayForge 面板。
2. 创建并接入入口节点。
3. 按需要添加出口节点或内网节点。
4. 创建直连、中继或反向中继隧道。
5. 创建 TCP/UDP 转发服务。
6. 使用面板监控状态、流量和链路健康度。

## 适用场景

### 个人基础设施

统一管理云服务器、家庭宽带、NAS、软路由和实验室节点。

### 远程办公与维护

在不改变内部网络结构的情况下，为经过授权的远程维护服务提供受控入口。

### 多地节点连接

将不同地域、不同网络环境中的节点组织成清晰的入口和出口链路。

### 内网服务访问

将内网 Web、远程桌面、文件服务和其他 TCP/UDP 服务映射到指定入口。

### 小型团队资源管理

通过用户、隧道权限、流量上限和限速规则，对共享网络资源进行分配。

---

## 面向长期运行设计

RelayForge 关注的不只是“能不能连通”，还包括长期维护体验：

- 面板设置保存在服务端，换电脑登录也能恢复。
- 节点配置通过加密 WebSocket 同步。
- Agent 支持断线重连和自动升级。
- 转发配置变更后会同步到节点。
- 流量达到上限后自动暂停，避免继续消耗。
- 删除、暂停、恢复和诊断都有明确的操作反馈。
- 支持从现有部署平滑接管和升级。

## 安全与隐私

RelayForge 适用于自有或明确授权的网络环境。

平台提供：

- JWT 管理会话
- PBKDF2-SHA256 密码存储
- AES-256-GCM Agent 通信加密
- 节点密钥身份认证
- WSS 安全连接支持
- 节点和用户资源权限控制
- 流量额度和限速控制

实际部署时，建议使用 HTTPS/WSS、强密码、独立的 JWT 密钥和最小化防火墙规则。

## 开始使用

### 面板一键部署

在一台已安装 Docker 的服务器上执行：

~~~bash
curl -fsSL https://github.com/WayneDuan/RelayForge-Release/releases/latest/download/panel_install.sh | bash
~~~

脚本会自动完成：

- 检测 IPv4/IPv6 环境并选择对应配置。
- 拉取 RelayForge 前端、后端和 MySQL 镜像。
- 初始化数据库结构和管理员账号。
- 保存部署配置并启动全部服务。

部署完成后，打开服务器显示的面板地址即可开始接入节点。

### 节点快速接入

在面板中创建节点，复制生成的 Linux 或 Windows 安装命令，在目标机器执行即可。Agent 安装完成后会自动连接面板并上报节点状态。

获取部署文件：

- 发布文件：https://github.com/WayneDuan/RelayForge-Release
- Windows 多端口转发说明：随项目文档提供

RelayForge / 铸流：

> 让每一条连接都可见、可控、可维护。
